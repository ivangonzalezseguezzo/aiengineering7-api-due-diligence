# Lupa Code — Pitch deck

## Problema
En los equipos de software, cada pull request espera en promedio un día por una revisión humana, y las
revisiones apuradas dejan pasar errores de seguridad.

## Solución
Lupa Code revisa cada pull request con un modelo de lenguaje: detecta errores, problemas de seguridad y
desvíos de las convenciones del equipo, y deja los comentarios en GitHub o GitLab en minutos.

## Tracción
- MRR de USD 60.000.
- 150 equipos de ingeniería pagos en América Latina y España.
- Crecimiento de 12 % mensual en los últimos seis meses.
- Margen bruto de 82 %.

## Ronda
Buscamos USD 5.000.000 (Serie A) a una valuación pre-money de USD 35.000.000 para sumar revisión de
arquitectura y abrir ventas en Estados Unidos.
